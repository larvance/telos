Version 0.1.0 — Alpha Release

Latest Release

October 12, 2026

  • Underwater Shading: Integrated 2D caustics water animation overlay and translucent geometry culling when submerged.
  • Corrected Texture Mappings: Dynamic BlockRegistry sync for OpenGL and Vulkan flora layers.
  • Tauri 2 Launcher: Redesigned modern launcher with advisory build locking and multi-instance launch management.
  • Multiplayer Server Groups: Reorderable server cards with draggable controls and collapsible sections.
  • World Generation: 3D procedural terrain with caves, aquifers, strata rules, and biomes.

Version 0.0.9 — Architecture Preview

Snapshot

October 05, 2026

  • Dual GPU Pipeline: Asynchronous compute queue and bindless buffer device address support on Vulkan 1.3.
  • Binary Greedy Meshing: 64-bit SIMD bitmask extraction for sub-millisecond chunk mesh generation.
  • Quinn QUIC Transport: Low-latency encrypted UDP transport with client prediction.
